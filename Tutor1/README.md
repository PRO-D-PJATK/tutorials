# Tutor1

### Task: Git and GitHub Proficiency Test

This task aims to test your ability to use Git and GitHub effectively while working with branches, pull requests, and repository management. You will create a simple script in any scripting language (e.g., Python, Bash) that uses the `--help` flag to display a help message. You will then manage this project using Git and GitHub, following the instructions below.

#### Instructions:

1. **Create a GitHub repository**:
   - Create a new GitHub private repository in this organisation with named `Tutor1_<your-student-numer>` (stuten number in version s12345).
   - Ensure the repository contains:
     - A `main` branch (default).
     - A `.gitignore` file (appropriate for the language you choose for your script).
     - A `README.md` file with a brief description of the project.
   
2. **Write the script**:
   - In any scripting language (e.g., Python, Bash, etc.), write a script that accepts a `--help` flag.
   - When the script is run with the `--help` flag, it should display a simple help message explaining its functionality. The script itself can be basic, such as printing text or performing a simple operation.

3. **Branch and Commit**:
   - Create a new branch called `feature-help-script`.
   - Add your script to this branch and commit your changes.
   - Push the `feature-help-script` branch to GitHub.

4. **Pull Request**:
   - Create a pull request from `feature-help-script` to `main`.
   - Add at least one person from the group as a reviewer, BUT NOT A TEACHER!.
   
5. **Review and Merge**:
   - After receiving feedback (or after a reasonable amount of time), merge the pull request into the `main` branch.

6. **Submit your repository**:
   - After completing the task, submit the URL of your GitHub repository, in return to assignment.

#### Grading Criteria (10 points total):
1. **Repository Structure** (2 points):
   - Repository correctly created with `.gitignore` and `README.md`.
   
2. **Branching** (2 points):
   - A separate branch `feature-help-script` is correctly created and used for development.
   
3. **Pull Request** (2 points):
   - A pull request is correctly created from the `feature-help-script` branch to `main`, and a group member is added as a reviewer, but niot a TEACHER!.
   
4. **Script Functionality** (2 points):
   - The script correctly handles the `--help` flag and displays an appropriate help message.
   
5. **Git Usage** (2 points):
   - Proper use of Git, including clear and meaningful commit messages and appropriate branch management.

Good luck!
