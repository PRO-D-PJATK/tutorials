# Tools for Work Organization

### 1. **Tools for Work Organization and Project Management**
   - **Trello/Asana** – for task management and organizing group work, tracking project progress.
   - **Notion** – a comprehensive tool for managing notes, plans, and schedules.
   - **Git and GitHub/GitLab** – for versioning code and collaborating on projects within a team.
   - **Slack/Discord** – group communication and information exchange during project work.
   
### 2. **Tools for Writing and Formatting Documents**
   - **Microsoft Word/Google Docs** – basic text editing tools with features for collaborative editing, change tracking, and formatting.
   - **LaTeX (Overleaf)** – a tool for professional formatting of scientific documents, particularly useful for writing more technical engineering papers.
   - **Zotero/Mendeley** – bibliographic managers for managing citations and literature, automatically generating footnotes and bibliographies.
   
### 3. **Tools for Data Analysis and Chart Creation**
   - **Python (pandas, matplotlib, seaborn)** – tools for data analysis and visualization in engineering work.
   - **R** – another tool for statistical analysis and data visualization.
   - **Tableau/Power BI** – for creating advanced reports and interactive data visualizations.
   
### 4. **Tools for Text Quality Checking**
   - **Grammarly** – a tool for checking grammatical correctness of text (in English).
   - **Hemingway App** – a tool to help simplify and improve the clarity of text.
   - **LanguageTool** – a multilingual tool for checking grammatical correctness.
   
### 5. **Tools for Coding Support**
   - **Visual Studio Code** – a code editor with a wide range of plugins that allows for writing documentation alongside code.
   - **Jupyter Notebook** – for creating documents that contain code, calculations, charts, and text.
   - **Docker** – a containerization tool that allows running projects in a controlled environment.
   
### 6. **Tools for Creating Presentations**
   - **Canva** – an online tool for creating professional presentations, diagrams, graphics, and other visual materials.
   - **PowerPoint/Google Slides** – classic tools for creating presentations.
   - **Prezi** – a presentation tool in which we create a large poster and move around in it

### 7. **Tools for Plagiarism Checking**
   - **Plagscan/Turnitin** – tools for detecting plagiarism in written work.

### 8. **Tools for Supporting Creative Thinking and Mind Mapping**
   - **MindMeister** – an online tool for creating mind maps that help organize and develop ideas.
   - **XMind** – an application for creating diagrams and mind maps, especially useful during the planning phase of work.

### 9. **Tools for Versioning and Code Control**
   - **GitHub/GitLab/Bitbucket** – repositories for versioning code and documentation.
   - **Sourcetree** – a graphical client for Git version control systems, which simplifies repository management.

### 10. **Tools for Data Processing and Modeling**
   - **MATLAB** – for mathematical computations and simulation modeling.
   - **Simulink** – for modeling dynamic systems, e.g., in automation or robotics.
