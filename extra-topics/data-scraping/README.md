# Data Scraping

Collect data programmatically from **websites** and from **streams**. Complete **both** sub-tasks below (each lives in its own subfolder).

**Total: 18 points** (8 + 10)

| Subfolder | Focus |
|-----------|--------|
| [website-scraping](website-scraping/) | HTML / site scraping with respect for robots and ToS |
| [stream-scraping](stream-scraping/) | Collecting records from a live or simulated stream |

## Shared rules

1. Prefer sites/APIs that **allow** educational scraping; cite robots.txt / ToS.
2. Rate-limit requests; never hammer a server.
3. Store raw captures separately from cleaned tables.
4. No credentials or personal data of private individuals in the repository.
5. If a real site blocks you, use a documented public sandbox / sample HTML / mock stream — and state that clearly.
